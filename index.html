FEATURES

Built different.

No binary blobs, no hidden init hooks, no unnecessary abstractions. Just source code and shell scripts.

PKG_MGR

Astral

A 10k+ line monolithic POSIX sh package manager. Source builds, GPG signing, rollback transactions, parallel installs, service management.

BOOTSTRAP

Horizon

Three-stage LFS-style bootstrap engine. Builds your entire system from scratch — toolchain, chroot, final install. Automated. Reproducible.

RECIPES

.stars Format

Three recipe format versions with full backwards compatibility. Build hooks, split dependencies, post-install scripts, git source support.

REPOS

AOHARU + ASURA

Official curated repository (AOHARU) and a community overlay (ASURA). Both indexed and served via GitHub Pages with optional GPG verification.

INIT

Init Freedom

No forced init system. Astral detects systemd, OpenRC, runit, s6, SysVinit automatically and adapts service commands accordingly.

SECURITY

Verified Builds

SHA256 checksums, GPG package signing, Web of Trust, file integrity monitoring, audit trail. Toggle safety levels via make.conf.
